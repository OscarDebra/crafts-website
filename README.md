# Crafts Website

This will be a website for my mother. She buys old chairs and renovates them. Currently she sets the renovated chairs for sale on finn, but she wanted a way to catalogue her work, this is what the website is for.


## Home page

The home page will be where all the works are displayed, in boxes that wrap around the screen.


## Project page

The project page will be reached whenever a user clicks on any given item. It will display pictures of before and after the renovation and general information about said object.


## Admin page

The admin page will be where you submit new projects and make pages for them. It will need to be user friendly and easy to understand for our clients.
